All the Way Down

A computer built from several thousand NAND gates and nothing else, wired and simulated gate by gate inside this page. The screen shows a program running on it. Under the screen is every layer below: the program, the machine code, the processor, the gates, and the one gate they are all made of.

Written in Turtle, a small C-like language. This page compiled it a moment ago, with a compiler that assigns registers by graph colouring. 3 The machine code 

      
The compiler's output: N16 assembly. Every line is one instruction, and every instruction takes exactly one clock cycle.

      

    

    

      
4 The processor N16

      
Sixteen bits, eight registers, one cycle per instruction. These values are read straight from the flip-flops.

      

    

  


  

    

      
6 The NAND gate the bottom

      
Its output is 0 only when both inputs are 1. That is the whole rule. The adders, the multiplier, the register file and every program above are this gate, repeated. Click the inputs.
